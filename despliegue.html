OpoClaro usa archivos estáticos: HTML, CSS, JavaScript y SVG. No necesita servidor de aplicaciones, base de datos, claves, API de pago ni proceso de compilación.

Publicar con Cloudflare Pages

Puedes publicar con el subdominio asignado en pages.dev sin comprar un dominio aparte. El plan gratuito de Cloudflare Pages admite sitios estáticos; revisa la tabla oficial de límites porque las condiciones pueden cambiar. Un dominio propio es opcional y normalmente requiere compra.

  1. Elige cómo subir los archivos.

    Para una publicación sencilla, inicia sesión en Cloudflare, abre Workers & Pages y crea un proyecto de Pages con carga directa. También puedes conectar un repositorio Git para desplegar cada cambio al actualizar la rama elegida. La guía oficial de Cloudflare explica las opciones. Ten en cuenta que un proyecto de carga directa no se puede cambiar después a integración Git; si quieres despliegues automáticos, elige Git al crear el proyecto.

  2. Usa esta carpeta como raíz.

    Sube el contenido completo de oposita-claro, incluyendo index.html, assets/, herramientas/ y guias/. No selecciones un directorio de compilación: no hay comando de build ni dependencias; el propio contenido de esta carpeta está listo para publicarse.

  3. Comprueba la vista previa.

    Visita la dirección *.pages.dev asignada por Cloudflare. Abre cada página interior desde un móvil o con la ventana estrecha del navegador. Comprueba calculadora, navegación y guardado del plan.

  4. Actualiza el dominio de ejemplo.

    Comprueba que las URL canónicas, los metadatos y el sitemap usan tu dominio público actual, siempre con HTTPS y con la ruta correcta de cada página. Si cambias de dominio en el futuro, actualiza también la referencia de robots.txt.

  5. Registra la propiedad en Search Console.

    En Google Search Console, añade la propiedad URL-prefix con la dirección pública. Usa el método de etiqueta HTML y pega el código de verificación en el meta google-site-verification de index.html. Publica el cambio y pulsa Verificar.

  6. Envía el sitemap.

    En la sección Sitemaps de Search Console, envía https://opoclaro.santi2326ph.workers.dev/sitemap.xml. El archivo robots.txt ya indica dónde encontrarlo. Solicita indexación para la portada y las páginas principales si lo deseas.

Cuando quieras desplegar cambios

En carga directa, vuelve a subir el contenido completo del directorio. Con Git, confirma el cambio y Cloudflare Pages ejecuta el despliegue automáticamente. Para ambos métodos la raíz publicada sigue siendo la carpeta con index.html.

Search Console, no analítica invasiva

Se incluye un espacio para la etiqueta de verificación de Search Console y metadatos SEO básicos. La verificación da acceso a informes de búsqueda; por sí sola no añade un script de seguimiento a tus visitantes.

Si en el futuro incorporas Google Analytics, revisa primero sus requisitos de consentimiento y privacidad aplicables a tu audiencia y ubicación.

Preparada para anuncios más adelante

El diseño deja áreas de contenido modulares para que puedas valorar una integración futura. No carga código de AdSense, no muestra anuncios y no tiene un archivo ads.txt activo. Antes de solicitar monetización, añade una política de privacidad adecuada y revisa los requisitos vigentes de Google.

Contenido útil

La estructura contiene herramientas funcionales y guías originales relacionadas entre sí; no crea páginas repetidas automáticamente ni páginas vacías para palabras clave.
